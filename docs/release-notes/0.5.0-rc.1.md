# Minecraft Launcher 0.5.0-rc.1

Release Candidate первой публичной версии:

- понятный первый запуск с подключением по базовому URL сервера;
- отдельные главный экран и настройки с приоритетом действия «Играть»;
- обновления Launcher перенесены в настройки;
- оригинальная нейтральная cube/play-иконка для приложения и установщика;
- сохранены Minecraft/Fabric launch, managed Java, Pack Manifest v1, SHA-256 sync, Repair и Velopack self-update.

Сборка не подписана кодовой подписью. Получайте RC только из официального репозитория проекта.
