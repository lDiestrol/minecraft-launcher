# Minecraft Launcher 0.4.0-rc.1

Первый устанавливаемый Release Candidate:

- per-user Setup.exe и portable ZIP для Windows x64;
- self-contained .NET 10 приложение;
- подготовка Minecraft 1.20.1, managed Java и точной версии Fabric;
- Pack Manifest v1, SHA-256 sync и Repair;
- ручная проверка, загрузка и применение обновлений Launcher через Velopack;
- разделённые каталоги приложения и постоянных игровых данных.

Сборка не подписана кодовой подписью. Получайте RC только из официального репозитория проекта.
