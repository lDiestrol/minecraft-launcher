# Minecraft Launcher v0.6.0

В этом обновлении мы полностью переработали внешний вид Launcher, улучшили управление игровыми сборками и добавили защиту файлов работающего Minecraft.

## Что нового

- Полностью обновлённый тёмный интерфейс.
- Более удобные настройки и навигация.
- Быстрый доступ к папкам игры, модов, ресурспаков и шейдерпаков.
- Возможность удалить файлы установленной сборки и скачать их заново.
- Автоматическое восстановление отсутствующих и повреждённых файлов сборки.
- Защита от случайного удаления и изменения файлов, пока Minecraft запущен.
- Повышенная стабильность при одновременной работе нескольких копий Launcher.

## Сохранность пользовательских данных

При удалении или восстановлении сборки сохраняются пользовательские миры, скриншоты, ресурспаки, шейдерпаки, самостоятельно добавленные моды и другие личные файлы, которые не входят в сборку Launcher.

## Обновление с v0.5.0

После официальной публикации пользователи установленной версии v0.5.0 смогут обновиться до v0.6.0 через встроенную систему обновлений Launcher.

## Windows SmartScreen

Приложение пока не подписано цифровым сертификатом, поэтому Windows может показать предупреждение при первом запуске установщика.

Скачивайте Launcher только с официальной страницы GitHub Releases проекта и при необходимости сверяйте контрольную сумму SHA-256.
