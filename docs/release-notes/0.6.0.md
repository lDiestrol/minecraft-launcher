# Minecraft Launcher 0.6.0

Версия 0.6.0 обновляет интерфейс и усиливает защиту игровых сборок:

- новый Dark Gaming UI с единой тёмной темой и обновлённой навигацией;
- улучшенные Settings и новое оформление окна на базе WindowChrome;
- быстрый доступ к папкам выбранного игрового профиля;
- безопасное удаление только тех файлов сборки, которые находятся под управлением Launcher;
- Repair и повторная загрузка недостающих или повреждённых managed-файлов;
- GameProcessGuardian сохраняет защиту профиля, если Launcher закрыт, а Minecraft продолжает работать;
- межпроцессная синхронизация защищает общие Minecraft libraries, assets, Fabric и managed Java от конкурирующих операций;
- пользовательские settings, saves, screenshots, resource packs, shader packs и другие unmanaged-данные сохраняются при Repair, удалении managed-файлов и обновлении Launcher.

Сборка для Windows x64 является self-contained и не подписана Authenticode. Получайте установщик только из официального GitHub repository/release source проекта и сверяйте SHA-256.
